# Trace Expert City booking system

Small admin-side booking demo for the space-rental hackathon.

## Run

Requires Node.js 18 or newer. Run `npm start`, then open `http://localhost:3000` once the server exists.

## Team start

Read [TEAM.md](TEAM.md) before starting. The selected persistence layer is JSON so the team can demonstrate the booking rule without waiting on dependency installation.
